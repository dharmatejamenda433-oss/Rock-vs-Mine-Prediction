# Sonar Rock vs Mine Prediction

This project uses Machine Learning to classify sonar signals as Rock or Mine.

## 🔹 Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn

## 🔹 Model Used
Logistic Regression

## 🔹 Steps Performed
1. Data Collection
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Accuracy Evaluation

## 🔹 Accuracy
Model achieves around 80%+ accuracy.
